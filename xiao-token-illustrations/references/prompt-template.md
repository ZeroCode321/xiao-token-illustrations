# 生图提示词

按需填写，不要把占位符原样交给模型。用户给了参考图时，在调用图像工具时实际传入图片，并说明其作用。

## 单张正文配图

```text
用途：中文文章正文配图，默认 16:9 横版。
核心意思：{一句话}。
画面：{小token正在做的具体动作，以及一两件必要物件}。
参考图（仅在用户提供时填写）：纸张或原始草图用于暖米白纸张质感和自然墨线；三视图用于锁定小token的头身比例和空心线条造型。不要复制参考图的三栏排版、标签、辅助线、问号或表情示例。
风格：可见但克制的暖米白纸纹，深褐黑色手绘线条，轻微笔触起伏，充足留白；必要时少量红橙蓝批注。
文字：{精确的中文短词；无文字则明确写“不要文字”}。
约束：小token承担核心动作；一个画面只讲一个意思；不要黑色实心角色、纯白数码底色、PPT信息图、复杂界面、阴影、渐变或多余标题。
```

## 三视图

```text
用途：小token角色三视图设定。
画面：从左到右为正面、侧面、背面，等高、头顶和脚底对齐；头约1/4、躯干约1/2、腿约1/4。正面双眼，侧面单眼，背面无五官。
参考图（仅在用户提供时填写）：原始草图决定暖纸底色和手绘气息；已有三视图决定角色结构与一致性。
背景：轻柔暖米白纸张和细微纤维纹理，不要纯白。
文字：只写“正面”“侧面”“背面”，除非用户另外指定。
约束：不要加入表情参考、额外角色、问号或现代数码渐变。
```

## 局部编辑

```text
编辑目标：{只修改的部分}。
保持不变：小token的角色比例、暖纸底色及纹理、其余线条、姿势、标签、版式和图片尺寸。
不要新增任何未要求的物件或文字。
```
